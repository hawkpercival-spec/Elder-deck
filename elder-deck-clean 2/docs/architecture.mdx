# Technical Architecture

Elder Deck is built as a robust full-stack web application combining a high-performance React frontend with a secure Express backend.

## Stack Overview

- **Frontend**: React 19, TypeScript, Tailwind CSS, Lucide Icons, Motion.
- **Backend**: Express.js server (`server.ts`) bundling API endpoints with `esbuild`.
- **Database & Auth**: Firebase Firestore & Firebase Authentication (`/firestore.rules`).
- **AI Integration**: Google Gemini API (`@google/genai`) for bespoke meditation generation and destiny scroll synthesis.
